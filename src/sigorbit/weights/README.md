# Weights

`sigorbit-c8-257-v1.pt` is a slim inference artifact generated by
`scripts/slim_checkpoint.py`. It omits deterministic e2cnn filter caches and
training-only ArcFace/head state. The resulting embeddings are bit-identical to
the selected 257px training checkpoint.

- size: 17,738,933 bytes
- SHA-256: `ff62889e2c5172762e894f4ee05162e0109d06c863b1fa83a7bcc6baf1dc0963`
- semantic model ID: `sigorbit-c8-257-v1`

The checkpoint is intentionally absent from this directory and from public
builds. It exists only in an ignored external local path for pre-release
engineering. A full pixel audit
identified its training images as genuine CEDAR and BHSig260 samples. CEDAR has
no explicit licence grant; BHSig260 is stated only to be available “for research
purposes”. **Do not push, publish or redistribute the checkpoint** until the permissions in
`docs/DATASET_LICENSE_AUDIT.md` and `docs/RELEASING.md` are approved and a
weights-license file is added. The repository's MIT `LICENSE` governs source
code; `NOTICE` does not assert a redistribution grant for this checkpoint.
